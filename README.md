# Incentive Tracker releases

Public APK builds for in-app updates. This repository holds only `incentive-tracker.apk` and `latest.json` as release assets. Source code, logged hours, and the signing key are not published here.

## Install and update

The first update-capable build must be installed manually. Open its release, download `incentive-tracker.apk`, and install it over your existing Incentive Tracker. After that, when you first open the app each day, it checks for a newer build and offers **Update** or **Close** if one is available. You can also tap **i** > **Check for update** at any time. Tap **Update**, wait for the download, then tap **Install**. Android may ask once to allow Incentive Tracker to install apps. Existing logged days stay on the phone when the package and signing key match.

Only download APKs from this repository. Higher `build-N` numbers are newer. Updates are sideloaded through Android's installer, not silently installed.
